# CalorieMate

CalorieMate is a simple Flutter app designed for beginners. It helps users log meals, track calories, and see their daily totals without complicated setup.

## Features
- Add meals with a name and calorie count
- View total calories for today
- See all stored meal entries
- Delete meals if needed
- Save data locally with SharedPreferences
- Simple bottom navigation app structure

## Screens
1. Home screen: daily calorie summary and meal list
2. Add food screen: add food with name and calories
3. Summary screen: useful stats and recent entries

## Tech Stack
- Flutter
- Dart
- Provider for state management
- SharedPreferences for local persistence

## Run locally
```bash
flutter pub get
flutter run
```

## Project requirements covered
- Minimum 3 screens: yes
- Navigation: yes using BottomNavigationBar
- State management: yes with ChangeNotifier
- Persistence: yes using SharedPreferences
- User-friendly UI: yes
- Git version control: yes
