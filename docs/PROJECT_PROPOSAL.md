# Project Proposal

## Application Name
CalorieMate

## Concept
CalorieMate is a simple calorie tracking app that helps users quickly log meals and monitor daily calorie intake. It is designed for beginners and everyday users who want a lightweight way to stay on top of their nutrition without a complicated interface.

## Problem Statement
Many people want to improve their eating habits, but calorie tracking apps can feel too advanced or overwhelming. CalorieMate solves this by keeping the process simple: add a meal, enter calories, and see daily totals instantly.

## Target Audience
- Students
- Busy professionals
- Anyone beginning a healthier lifestyle
- People who want a simple wellness tool without advanced features

## Core Features
- Add a meal with a name and calorie count
- Display total calories consumed for the current day
- View and remove recent meal entries
- See quick daily summary information in a simple, clean dashboard

## Data Model / API
The app will store local user data in the device using SharedPreferences. The data model includes:
- meal id
- meal name
- calorie value
- date/time when it was added

This keeps the app simple, fast, and easy for a beginner to understand.
